# 🦀 Rust Başlangıç 1

![Rust](https://img.shields.io/badge/Language-Rust-orange)
![License](https://img.shields.io/badge/License-MIT-blue)

Bu proje, Rust programlama dilini öğrenme sürecimde oluşturduğum temel örnekleri ve alıştırmaları içermektedir. Amaç, Rust'ın temel kavramlarını pekiştirmek ve pratik yapmaktır.

---

## 🚀 Özellikler

- **Temel Rust Kavramları:** Değişkenler, veri tipleri, kontrol yapıları, fonksiyonlar.
- **Gelişmiş Konular:** Struct, Enum, Match ifadeleri, hata yönetimi.
- **Dosya Yapısı:** Modüler kod yapısı ile organize edilmiş örnekler.
- **CLI Uygulamaları:** Komut satırı tabanlı küçük uygulamalar.

---

## 🛠️ Kullanılan Teknolojiler

- **Programlama Dili:** Rust
- **Paket Yöneticisi:** Cargo
- **Kod Düzenleyici:** Visual Studio Code
